## Docker Commands 

#### Start and Stop Docker 
To stop Docker from running - `docker desktop stop` <br>
To check that it is stopped or running - `docker desktop status` <br> 
To start Docker - `docker desktop start` <br>
Test engine - `docker info`

#### Status stuff
Check running containers - `docker ps` <br>
Check existing containers - `docker ps -a` <br>
Check downloaded images - `docker images` <br>

Remove container - `docker rm <container_name>` <br> 
Remove image - `docker rmi <images_name>`
